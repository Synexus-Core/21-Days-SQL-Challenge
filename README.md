## 🛠️ How to Participate (The Rules)

To successfully complete the challenge and qualify for the rewards, you must follow this daily routine:

1. **Check the Repo:** Every evening, a new folder (e.g., `Day-01`) will be uploaded to this repository with the daily problem statement, requirements, and logic breakdown.
2. **Write the Code:** Build the relational solution on your local machine using MySQL and push the `.sql` files to your *own* personal GitHub repository. Make sure your repo is set to public visibility.
3. **Post on LinkedIn:** By Next End of Day (EOD), create a post on your updated LinkedIn profile showcasing what you engineered. Include a screenshot of your execution grid, an ER diagram, or a snippet of your query logic.
4. **Tag & Hashtag:** You **must** mention `@synexus` (our official LinkedIn Page) and include the following official hashtags in every daily post:
   
   `#21DaysSQL` `#Synexus` `#DatabaseDesign` `#MySQL` `#DataEngineering` `#SQL` `#BuildInPublic`
